# Security & Privacy Principles

IKHMAD may process highly sensitive emergency and location information.

Design principles include:
- data minimization;
- purpose limitation;
- explicit user consent where applicable;
- role-based access control;
- audit logs;
- secure transport;
- secure storage;
- restricted operator permissions;
- limited retention of sensitive data;
- separation of public and operational information;
- incident provenance and traceability.

Real personal data must never be committed to this public repository.
