# Data Sources

Potential IKHMAD data categories include:

- citizen-generated reports;
- professional operator inputs;
- satellite / thermal detections;
- weather observations and forecasts;
- geospatial road data;
- terrain and vegetation information;
- administrative boundaries;
- designated safe zones;
- institutional data feeds.

Specific providers, contracts, licenses, refresh rates and reliability policies may change during MVP development.

No third-party dataset is implied to be owned by IKHMAD merely because it is integrated into the platform.
