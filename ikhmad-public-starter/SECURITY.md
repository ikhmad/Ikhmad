# Security Policy

## Public repository safety

Do not commit:
- secrets or credentials;
- personal data;
- emergency-service operational credentials;
- private API keys;
- production database dumps;
- precise real-world user histories;
- confidential decision-engine implementation.

## Reporting security issues

Security issues should be reported privately to the project maintainers rather than posted publicly.

## Demo data

All examples in this repository should use synthetic or deliberately non-sensitive data.
