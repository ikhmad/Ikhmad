# Development Roadmap

## Phase 0 — Product prototype ✅
- citizen UX;
- command-center UX;
- incident reporting flow;
- alert flow;
- SOS flow;
- evacuation flow;
- dynamic rerouting concept.

## Phase 1 — Connected MVP ⏳
- account/session layer;
- incident/report API;
- persistence;
- command-center incident queue;
- realtime status updates;
- SOS API;
- alert delivery;
- basic GIS integration;
- audit trail.

## Phase 2 — External data + incident intelligence ⏳
- weather integration;
- geospatial layers;
- initial external wildfire feeds;
- source provenance;
- incident correlation;
- confidence interface;
- operator review tooling.

## Phase 3 — Predictive evacuation ⏳
- hazard evolution interface;
- route-safety service;
- safe-zone evaluation;
- event-driven route reassessment;
- degraded/offline behavior;
- simulation and validation.

## Phase 4 — Institutional pilot ⏳
- pilot deployment;
- responder/operator feedback;
- operational workflow validation;
- performance tests;
- safety review;
- privacy/security review;
- field-simulation exercises.

## Phase 5 — Scale ⏳
- multi-region deployment;
- high-availability architecture;
- institutional integrations;
- monitoring/observability;
- advanced analytics.
