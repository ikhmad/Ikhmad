# IKHMAD Intelligence Layer

The intelligence layer is represented in the public repository only as a system boundary.

Planned responsibilities include:

- multi-source incident correlation;
- source provenance and confidence assessment;
- dynamic hazard evaluation;
- route-safety evaluation;
- safe-zone evaluation;
- event-driven reassessment.

## Not published here

The public repository intentionally excludes:

- confidence formulas;
- calibrated source weights;
- thresholds;
- hazard prediction implementation;
- predictive routing internals;
- road traversability scoring;
- safe-zone ranking logic;
- anti-fraud logic;
- training or calibration data.

These components belong to IKHMAD's proprietary technology layer and should be developed in controlled/private repositories until the IP strategy is finalized.
