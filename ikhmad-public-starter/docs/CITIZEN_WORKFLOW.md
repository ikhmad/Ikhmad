# Citizen Workflow

## Normal use
1. User opens IKHMAD.
2. Location-aware home screen presents local status.
3. User opens the wildfire map.
4. User views nearby incident details and safety guidance.

## Report fire
1. User selects **Report Fire**.
2. Location is confirmed or adjusted.
3. User provides observation type and optional evidence.
4. Report is submitted.
5. IKHMAD returns an incident/report reference.
6. The report enters review / corroboration state.
7. Later status changes may be communicated to the user.

## SOS
1. User selects **SOS**.
2. The application requests explicit confirmation.
3. Current location and available emergency context are sent.
4. User receives an acknowledgment.
5. Command-center workflow displays the SOS request.

## Evacuation
1. User receives a warning.
2. IKHMAD presents relevant hazard information.
3. User starts evacuation guidance.
4. A safe destination and route are presented.
5. If conditions materially change, the route may be reassessed.
6. User receives arrival / safe-zone confirmation.
